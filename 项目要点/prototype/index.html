原始需求说明
2026-05-16 · 华电环保系统需求点整理
数据源（3 路）
  • 外部环保数据平台 — NOx、O₂、温度、流量、压力；分钟 / 小时 / 日 / 月 / 季 / 年报
  • 集团环保数据平台 — 数据字段同上
  • SIS 系统 — 机组负荷、脱硝数据；尿素用量 / 流量、空压机压力、SCR 前后 NOx 浓度等，作为辅助判定依据
一、数据质量与报警
  • 分钟数据不变 / 小时无变化 → 报警
  • 数值超标或不在正常运行范围 → 报警
  • 对实时小时数据计算剩余安全值 → 预警
  • 数据传输效率偏低 → 自动预警
  • 报警阈值可配置（小时均值 / 分钟值 / 日值）
  • 异常信息分类统计，支持时段筛选；以周报 / 月报 / 年报形式报送
二、CEMS 设备台账
  • 记录安装时间、可用时间、已用时间
  • 预期寿命更换提醒 + 维护 / 更换记录
  • 设备型号、厂家、图纸、说明书、排故方法
  • 备品备件台账（分类定额、采购时间、库存预警联动）
  • 库存不足自动提醒采购；库存寿命超标提醒
三、自动化环保报表
  • 从 3 路数据源 + 集团平台自动抓取数据生成报表
  • 月报 / 季报 / 年报按固定模板自动填报
  • 其他报表由各部门提供模板按需生成
四、企业环保信息管理
  • 企业基本信息台账
  • 排污许可证上传、变更台账管理
  • 排污许可证信息展示
  • 排放标准电子化展示（污染物指标、允许值、检测方法）
五、CEMS 定期工作管理
  • 拍照识别工作记录并上传服务器
  • 服务器按工作标准自动判定是否执行到位
  • 到期提醒：每周提前 2 天 / 每月 5 天 / 每季 10 天
六、第三方比对监测管理
  • 判定报告数据是否符合规范（方法、频次、数据）
  • 建立台账历史记录（按年份 / 季度 / 机组上传）
  • 废气 / 废水 / 噪声报告预警：每季度监测，提前 10 天提醒
七、预警发布通知平台
  • 环保工作公告 / 通知发布
八、环保历史台账
  • 历次环保检查问题整改台账
  • 记录发生时间、整改情况、验收人、整改人、整改材料
  • 实施闭环管理
九、环保培训
  • 收集集团 / 国家环保制度及法规
  • 自动生成题库，对环保人员进行在线培训
  • 统计并记录培训成绩
十、AI 应用探索（二期）
  • 利用 AI 学习相关制度
  • 上传集团 / 环保局案例，结合公司实际情况进行风险预警
